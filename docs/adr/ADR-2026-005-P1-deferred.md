# ADR-2026-005: P1 项延后处理

- **编号:** D-25 / ADR-2026-005
- **日期:** 2026-06-03
- **状态:** 延后处理
- **关联:** PRD §7 风险与依赖

## 背景

PRD 评审中识别出 4 项 P1 级别问题：IME 键盘适配、labelSmall Token 规范、语义角色标记、RTL 布局支持。这些项不阻塞当前功能交付，但影响完整性。

## 选项

1. 本期全部实现（延长交付周期约 3-5 天）
2. 标记为后续迭代，本期不纳入

## 决定

采用选项 2：P1 项标记为后续迭代处理，不纳入当前版本范围。具体包括：
- IME 键盘弹出时版本号被遮挡的适配
- Material3 labelSmall Token 的规范使用
- Compose 语义角色标记
- RTL（从右到左）布局支持

## 否决方案

- 选项 1：交付周期延长与增量价值不匹配，影响更优先功能的交付
