# ADR-2026-004: US-03 移除用户场景

- **编号:** D-24 / ADR-2026-004
- **日期:** 2026-06-03
- **状态:** 已移除
- **关联:** PRD §2 用户场景

## 背景

PRD 初稿中 US-03 描述的场景（用户通过系统设置查看版本号）经开发者确认不属于用户场景——Android 系统设置中的应用信息页面由系统自动生成，不经过应用代码。

## 选项

1. 保留 US-03，标记为"系统行为"
2. 从 PRD 中移除 US-03

## 决定

采用选项 2：从 PRD §2 中移除 US-03。该场景属于 Android 系统级功能，不在应用开发范围内。

## 否决方案

- 选项 1：保留无关场景会稀释 PRD 焦点，且验收标准无法针对系统行为编写
