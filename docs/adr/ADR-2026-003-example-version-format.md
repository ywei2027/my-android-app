# ADR-2026-003: 示例版本号统一格式

- **编号:** D-23 / ADR-2026-003
- **日期:** 2026-06-03
- **状态:** 已采纳
- **关联:** PRD.md, UI_DESIGN.md

## 背景

项目文档和 UI 预览中使用示例版本号时格式不统一，部分使用 `v1.0.0(42)` 等虚构值，与代码库实际版本号不一致。

## 选项

1. 使用代码库当前实际版本号作为示例
2. 使用通用占位符 `vX.Y.Z(code)`
3. 统一使用 `v1.0(1)` / `v1.0(1)debug` 作为示例

## 决定

采用选项 3：所有文档统一使用 `v1.0(1)`（Release）和 `v1.0(1)debug`（Debug）作为示例版本号，与代码库 `build.gradle.kts` 中的 versionName/versionCode 保持一致。

## 否决方案

- 选项 1：实际版本号会随每次构建变化，需要频繁更新文档
- 选项 2：占位符不够直观，UI 预览时无法展示真实效果
