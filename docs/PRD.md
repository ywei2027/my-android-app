## §1 功能概述

在 App 的「关于」页面中增加版本号显示，使用户能够直观地查看当前应用的版本名称和版本代码信息，便于问题反馈和版本管理。

## §2 用户场景

| 场景编号 | 角色 | 场景描述 |
|----------|------|----------|
| US-01 | 普通用户 | 用户在「关于」页面查看 App 版本号，用于确认是否需要更新 |
| US-02 | 测试人员 | 测试人员通过版本号确认当前安装的构建版本，用于 bug 复现和定位 |
| US-03 | 客服人员 | 客服引导用户查看版本号，判断用户是否已升级到修复版本 |

## §3 范围边界

### 包含
- 在「关于」页面显示版本名称（Version Name）
- 在「关于」页面显示版本代码（Version Code），始终显示
- 版本号数据从系统配置（build.gradle）自动读取

### 不包含
- 版本更新/升级功能
- 版本号编辑/修改功能
- 版本历史列表

## §4 验收标准

| 编号 | 验收项 | 预期结果 |
|------|--------|----------|
| AC-01 | 关于页面可见版本信息 | 页面显示 "v{versionName}({versionCode}){buildType}" 格式，如 "v1.0.0(42)release" |
| AC-02 | 版本号与 build.gradle 一致 | 显示的版本名称/代码与 gradle 配置一致 |
| AC-03 | 版本号不可编辑 | 版本号为纯展示，无输入框，无点击/长按交互 |
| AC-04 | 无障碍支持 | TalkBack contentDescription 包含完整版本信息，如 "当前版本 v1.0.0(42)release" |

## §5 非功能性需求

- **性能:** 版本号为静态读取，无额外性能开销
- **兼容性:** 适配 Android 8.0+（API 26+）
- **可维护性:** 版本数据统一由 build.gradle 管理

## §6 技术约束

- 使用 PackageManager 获取版本信息
- 版本名称与代码来自 build.gradle 的 versionName / versionCode

## §8 术语表

| 术语 | 说明 |
|------|------|
| versionName | 人类可读的版本号，如 "1.0.0" |
| versionCode | 内部版本整数，用于版本比较 |

## §9 UI 设计输入

### 页面清单
- 关于页面（AboutFragment / AboutActivity）

### 布局规格
| 属性 | 值 |
|------|-----|
| 版本号位置 | 页面内容区域中部，应用图标/名称下方 |
| 字体大小 | 14sp（次要信息） |
| 颜色 | 主题 onSurfaceVariant（D-13） |
| 视觉层级 | 不透明度 0.6 (60%) 降低视觉权重（D-19） |

### 交互规格
- 纯展示，无点击/长按自定义交互
- 版本号文字允许系统原生选中（textIsSelectable=true），不对齐 D-24 中的"关闭 textIsSelectable"（原生选中 ≠ 自定义交互）
- 降级态（Unknown）使用 `onSurfaceVariant` + opacity 0.5 与默认态区分

### 组件选型
| 组件 | 选型 | 原因 |
|------|------|------|
| 版本号显示 | TextView | 静态文本展示 |

### 设计约束
- 遵循 Material Design 3 风格
- 对齐现有关于页面的设计语言
