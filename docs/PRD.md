## 1. 功能概述

### 1.1 一句话描述
用户可以通过关键词搜索文章标题和内容，快速找到感兴趣的内容。

### 1.2 用户场景
| 场景 | 用户 | 操作 | 期望结果 |
|------|------|------|---------|
| S1-关键词搜索 | 普通用户 | 在搜索框输入关键词，点击搜索 | 返回匹配的文章列表，标题和正文摘要高亮关键词 |
| S2-空关键词 | 普通用户 | 不输入内容直接搜索 | 显示搜索提示（"请输入搜索关键词"）或展示热门搜索 |
| S3-无结果 | 普通用户 | 搜索一个不存在的关键词 | 显示"未找到相关结果"空状态，建议更换关键词 |
| S4-搜索历史 | 普通用户 | 点击搜索框（未输入） | 展示最近5条搜索历史，可点击复用或清空 |
| S5-网络错误 | 普通用户 | 搜索时网络断开 | 显示网络错误提示，提供重试按钮 |
| S6-加载更多 | 普通用户 | 搜索结果超过一页，滚动到底部 | 自动加载下一页 |

### 1.3 范围边界
- **包含**: 文章标题+正文全文搜索，搜索结果分页，搜索历史（本地存储5条），关键词高亮
- **不包含**: 语音搜索，图片搜索，高级筛选（标签/时间/分类），搜索建议/自动补全，后端搜索引擎迁移
- **待澄清**: 是否需要按时间排序？是否需要搜索范围筛选（仅标题 vs 全文）？

## 2. 页面与交互

### 2.1 页面清单
| 页面 | 路由 | 输入 | 输出 | 状态 |
|------|------|------|------|------|
| 搜索入口 | `/search` | 用户从首页点击搜索图标进入 | 搜索框 + 搜索历史列表 | 新建 |
| 搜索结果 | `/search?q={keyword}` | 关键词 | 文章列表（标题+摘要+高亮）+ 分页 | 新建 |
| 搜索结果-空 | `/search?q={keyword}` | 无匹配结果 | 空状态插画 + 提示文案 | 新建 |

### 2.2 关键交互流程
```
主路径：
  首页点击搜索图标 → 搜索页（展示历史记录） → 输入关键词 → 点击搜索/键盘确认
  → 搜索结果列表（标题+摘要，关键词高亮） → 点击结果项 → 文章详情页

分支路径：
  - 空输入点击搜索 → Toast提示"请输入关键词"
  - 搜索无结果 → 空状态页（"未找到'{keyword}'相关结果"），建议更换关键词
  - 网络错误 → 错误提示 + 重试按钮
  - 清空搜索框 → 回到搜索历史页

搜索历史：
  每次成功搜索后 → 本地存储关键词（最近5条，去重）
  点击历史项 → 直接触发搜索
  点击清空按钮 → 清除全部历史
```

### 2.3 边界情况
| 情况 | 处理方式 |
|------|---------|
| 加载中 | 骨架屏（搜索框下方显示 3 个 placeholder item） |
| 空数据（无历史） | 搜索框下方留白，无历史区域 |
| 空数据（无结果） | 居中的空状态插画 + "未找到相关结果" + "换个关键词试试" 建议 |
| 网络错误 | Snackbar 显示"网络连接失败"，底部固定重试按钮 |
| 权限不足 | 不涉及（搜索功能无需特殊权限） |
| 键盘处理 | 点击搜索按钮后收起键盘；滚动列表时收起键盘 |
| 特殊字符输入 | 过滤 XSS 相关字符，限制输入长度 100 字符 |

## 5. 验收标准

- [ ] AC-1: 在搜索框输入关键词并搜索，返回匹配标题或正文的文章列表
- [ ] AC-2: 搜索结果中关键词在标题和摘要中高亮显示
- [ ] AC-3: 搜索无结果时展示空状态提示
- [ ] AC-4: 搜索历史保存最近5条，点击可复用
- [ ] AC-5: 网络错误时显示错误提示和重试按钮
- [ ] AC-6: 搜索结果支持分页加载（滚动到底部自动加载下一页）

## 6. 依赖与风险

| 类型 | 描述 | 影响 | 缓解措施 |
|------|------|------|---------|
| 后端依赖 | 搜索接口需要后端提供全文搜索 API | 高 — 接口未就位则无法联调 | 前端先用 Mock 数据开发，接口就位后再联调 |
| 性能 | 大量文章时搜索延迟可能影响体验 | 中 | 添加防抖（300ms）、分页加载、考虑本地缓存 |
| UI 规范 | 搜索页 UI 尚无设计稿 | 中 | 先参考 Material Design 搜索规范实现，后续对齐 Figma |
