一、总则

1.1 本协议是您（下称"用户"）与本应用（下称"本平台"）之间关于使用本平台服务所订立的协议。

1.2 本协议内容包括协议正文以及本平台已经发布或将来可能发布的各类规则。

1.3 用户在使用本平台提供的各项服务之前，应仔细阅读本协议。用户一旦使用本平台服务，即视为已阅读并同意接受本协议全部条款的约束。

二、账号注册与使用

2.1 用户在使用本平台服务前需要注册账号。账号应当使用手机号进行注册。

2.2 用户在注册时应提供真实、准确的个人信息，并在信息变更时及时更新。

2.3 用户注册成功后，本平台将给予每个用户一个用户账号及相应的密码，该账号和密码由用户负责保管。

2.4 用户应对其账号进行的所有活动和事件负法律责任。

三、用户信息保护

3.1 本平台重视用户个人信息的保护，保护用户个人信息是本平台的一项基本原则。

3.2 本平台将按照相关法律法规的规定，采取合理必要的措施保护用户的个人信息安全。

3.3 用户在注册账号或使用本服务的过程中，可能需要填写或提交一些必要的信息。如用户提交的信息不完整或不符合法律法规的规定，则用户可能无法使用本服务或在使用本服务的过程中受到限制。

四、用户行为规范

4.1 用户在使用本平台服务过程中，必须遵循以下原则：

  • 遵守中国有关的法律法规；
  • 不得为任何非法目的而使用网络服务系统；
  • 遵守所有与网络服务有关的网络协议、规定和程序；
  • 不得利用本平台进行任何可能对互联网的正常运转造成不利影响的行为。

五、免责声明

5.1 本平台不对用户在本平台服务中相关数据的删除或储存失败负责。

5.2 本平台有权根据实际情况自行决定单个用户在本平台服务中数据的最长储存期限，并在服务器上为其分配数据最大存储空间等。
